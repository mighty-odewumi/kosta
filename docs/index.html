Kosta API

A payments backend for wallet apps: wallets, transfers, bank withdrawals with review, and deposits from payment providers. It keeps a proper ledger, so balances are always right and money can never be spent twice.

Every request below fills in these wallet ids for you, and a fresh Idempotency-Key is made each time you press Execute. Things to try:

  1. Transfers > Send money to another wallet > Execute. Then check Wallet A again.
  2. Set the amount higher than the balance to see insufficient_funds.
  3. Type your own Idempotency-Key and press Execute twice: the second answer is a replay and no extra money moves.
  4. Withdrawals > Withdraw to a bank account, then Admin > Approve a withdrawal.
  5. Admin > Check the books balance.
